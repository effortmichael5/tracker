# Траты: трекер расходов и нет-баланса

Веб-приложение для iPhone. Работает без интернета, а при появлении сети отправляет данные в Google Таблицу.
Всё бесплатно: хостинг на GitHub Pages, база в Google Таблице.

## 1. База: Google Таблица (5 минут)

1. Создай новую таблицу на sheets.google.com.
2. Меню **Расширения → Apps Script**. Удали всё, что там есть, и вставь код из `google-apps-script.gs`.
3. В первой строке замени `поменяй-меня` на свой секрет (любая длинная строка).
4. Нажми **Развернуть → Новое развертывание**. Тип: **Веб-приложение**.
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
5. Разреши доступ (Google предупредит, что приложение не проверено: «Дополнительно → Перейти»).
6. Скопируй URL вида `https://script.google.com/macros/s/.../exec`.

Листы «Счета» и «Операции» появятся сами при первой синхронизации.
Колонка `delta` показывает, как операция изменила общий баланс: расход с минусом, доход с плюсом, перевод 0. Удобно для сводных таблиц.

В версии 2 добавились колонки `bank` и `currency`. Если поменяешь код скрипта: **Развернуть → Управление развертываниями → Изменить → Новая версия**, иначе изменения не применятся.

## 2. Хостинг: GitHub Pages (5 минут)

1. На github.com создай **публичный** репозиторий, например `tracker`.
2. **Add file → Upload files**, перетащи файлы: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`. Нажми Commit.
3. **Settings → Pages**: Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`, Save.
4. Через минуту сайт будет по адресу `https://<твой-логин>.github.io/tracker/`.

В коде нет ни секрета, ни данных: их вводишь только в приложении на телефоне.

## 3. Установка на iPhone

1. Открой ссылку в **Safari**.
2. Кнопка «Поделиться» → **На экран «Домой»**.
3. Запусти приложение с иконки → **Настройки** → вставь URL скрипта и секрет → «Сохранить и синхр.».

После этого приложение открывается и работает без интернета.

## Как пользоваться

- **Счета**: выбери банк из списка (100 крупных банков РФ, поиск по первым буквам) или впиши свой, добавь реквизиты и текущий баланс. Чтобы поправить баланс, открой счёт и введи новую сумму; разница запишется как «корректировка».
- **+**: расход, доход или перевод между счетами. На компьютере: клавиша N.
- **Обзор**: нет-баланс, расходы и доходы за месяц, расходы по категориям, последние операции. Кнопка «Все операции» открывает историю с поиском и фильтрами.
- **Настройки**: валюта, имя пользователя, синхронизация, бэкапы.

## Бэкап MySQL и анализ в Beekeeper Studio

1. **Настройки → Бэкап MySQL (.sql)**. На iPhone откроется меню «Поделиться»: сохрани в «Файлы», AirDrop на Mac или отправь себе.
2. В Beekeeper Studio подключись к MySQL и создай базу: `CREATE DATABASE tracker;`
3. Открой `.sql`-файл в новой вкладке запроса и выполни всё.

Таблицы: `users`, `accounts`, `transactions`. Готовые представления:
- `v_expenses_by_month`: расходы по месяцам и категориям;
- `v_cashflow_by_month`: доходы, расходы и изменение баланса по месяцам;
- `v_account_balances`: балансы счетов.

Повторный импорт безопасен: данные этого пользователя заменяются свежими. Бэкапы разных людей (у каждого своё имя в Настройках) складываются в одну базу, их можно сравнивать.

Важно: данные лежат внутри приложения на экране «Домой». Если удалить иконку, локальные данные пропадут, но в таблице они останутся.

## Версия 3.0: новый дизайн

- Дизайн в стиле банковского приложения: стальной-голубой фон, кремовые стеклянные карточки, тёмно-синий, оранжевое кольцо. Тёмная тема тоже есть.
- Обзор: сводка месяца, карточка нет-баланса с плашками счетов, кнопки «Расходы» и «Доходы», последние траты списком или диаграммой.
- Страницы «Расходы», «Доходы», «Все операции»: категории-кнопки с ×. × убирает категорию из подсчёта, нажатие на убранную возвращает её. Сверху — предбаланс по учтённым категориям. Балансы счетов от этого не меняются.
- Настройки — шестерёнка вверху справа, разделы открываются отдельными страницами.
- Окна открываются без клавиатуры и закрываются свайпом вниз.

### Как обновить
Загрузи на GitHub (репозиторий tracker) файлы: index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png.
Скрипт Google Таблицы не менялся. Все данные на телефоне сохранятся.

## Версия 3.1: темы, иконки, аккаунты

- Профиль (нажми на кружок с инициалами слева вверху): имя, аккаунт, карусель тем — «Сталь», «Закат», «Мята», «Лаванда», «Неон», у каждой светлый и тёмный вариант.
- Главная: нет-баланс сразу под приветствием, счета — листаемые карточки, у категорий свои нарисованные иконки.
- Аккаунты: регистрация и вход по логину и паролю. Данные хранятся в аккаунте и появляются на любом телефоне после входа.

### Как включить аккаунты
1. В Google Таблице: Расширения → Apps Script → замени весь код на новый `google-apps-script.gs` → 💾.
2. Развернуть → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть. Ссылка /exec не меняется.
3. Чтобы друзьям не приходилось вводить ссылку на сервер: в начале `index.html` впиши её в `const DEFAULT_SERVER = '';`
   (между кавычками) и загрузи `index.html` на GitHub. Без этого при регистрации появится поле «Ссылка на сервер».
4. В приложении: профиль → «Создать аккаунт». Данные с телефона можно перенести в аккаунт.

В таблице появятся скрытые листы «Пользователи» и «Сессии». Пароли там не хранятся — только хэш с солью.
Ты как владелец таблицы видишь операции всех пользователей на листе «Операции» (колонка userId).
Старый режим с секретом (без аккаунта) продолжает работать.
